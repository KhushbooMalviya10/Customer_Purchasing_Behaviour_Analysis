# Customer_Purchasing_Behaviour_Analysis
Customer Purchase Behaviour Analysis | SQL + Python
Project Overview

This project analyzes customer purchasing behavior using SQL and Python (Pandas, NumPy) to identify spending patterns, customer segments, and sales trends. The goal is to transform raw transactional data into meaningful insights that support business decision-making and customer strategy.

Objectives
Analyze customer purchase patterns and spending behavior
Identify top customers and repeat customers
Evaluate sales performance and payment method usage
Segment customers based on purchasing activity
Generate insights to support marketing and retention strategies
Tools & Technologies
SQL — Data extraction, filtering, aggregations
Python — Data analysis and transformation
Libraries Used: Pandas, NumPy
Environment: Jupyter Notebook / VS Code
Dataset Description

The dataset contains customer transaction records with the following fields:

Customer ID
Order ID
Product Category
Purchase Amount
Quantity
Payment Method
Order Date
Customer Location
Project Workflow
1. Data Cleaning
Removed missing and duplicate records
Standardized column formats
Validated data consistency
2. Data Processing
Loaded dataset using Pandas
Converted data types where necessary
Created calculated fields for analysis
3. Data Analysis Using SQL
Identified top customers by total spending
Calculated repeat customer frequency
Analyzed sales trends and transaction counts
Filtered high-value orders
4. Data Analysis Using Python
Performed statistical summaries
Grouped customers by purchase behavior
Calculated total revenue and average order value
Generated customer segmentation insights
